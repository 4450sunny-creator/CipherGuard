TRANSPARENCY

Know where your data goes.

Security tools should be clear about what they process, what they store, and what they cannot promise.

⌑

Processing and storage

Uploaded files are processed by the Flask server running the application. Temporary copies and generated outputs are stored in the local instance/ directory and are not automatically purged in this version.

🔑

Passphrases

Passphrases are used in memory to derive encryption keys and are not written to the audit log. Use strong unique passphrases; lost passphrases cannot be reset by this prototype.

▤

Audit metadata

The app records action type, file name, byte count, and outcome in a local JSONL file. It is not tamper-proof and may contain private filenames.

!

Deployment warning

Do not expose the development server directly to the internet. Production needs authentication, CSRF protection, rate limiting, safe isolation, monitoring, and independent security review.

ⓘ File scan limits

Scanning is heuristic and only analyzes supported text extensions. It is not malware detection, full data-loss prevention, or proof a file contains no secrets. Binary documents and archives are not deeply inspected.
