ABOUT THE PROJECT

Security should be understandable.

CipherGuard is an educational data-protection workbench combining sensitive-pattern discovery, authenticated file encryption, integrity verification, and interactive learning.

THE MISSION

Make invisible risks easier to see.

People share project folders, configuration files, and documents without realizing they may contain credentials or personal information. CipherGuard helps users inspect supported text files, understand possible exposure, protect selected files, and verify encrypted data before recovery.

It explains the techniques it uses, shows detection limitations, and includes a lab where users can observe integrity checks in action.

FEATURES IN DETAIL

What's included in this version.

01

Pattern-based scanner

Checks supported text files for private-key markers, common token patterns, secret-like assignments, emails, Indian mobile-like numbers, and private IPs. Reports counts and line numbers without revealing matched values.

02

Authenticated encryption

Uses AES-256-GCM with fresh salt and nonce. Scrypt derives a key from the passphrase. Header metadata is authenticated as associated data.

03

Verified decryption

Rejects malformed formats, incorrect passphrases, and tampered ciphertext. Download names are sanitized.

04

Security test lab

Demonstrates round trips and intentional ciphertext modification using synthetic text.

05

Safer file handling

Enforces size and extension limits, uses random temporary names, and stores files outside the static web directory.

06

Metadata-only audit trail

Records basic actions without recording passphrases or detected secret values. The local log is not tamper-proof.

ⓘ Educational prototype

CipherGuard is not a certified security product. The scanner is heuristic and incomplete, the audit log is not tamper-proof, and the web app is not hardened for public multi-user deployment. Use test data while learning and never rely on a prototype as the only protection for important files.
