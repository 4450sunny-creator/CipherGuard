Local pattern-based inspection · max 12 MB

Privacy note: the file is processed by this server instance. Use only files you are authorized to inspect. Avoid real sensitive data on public deployments.

What can it detect?

  • Private-key block markers
  • Common API token patterns
  • Secret-like assignments
  • Email addresses
  • Indian mobile-like numbers
  • Private IPv4 addresses

Know the limits

Pattern scanning can miss secrets and produce false positives. PDFs, images, and binary files are not deeply inspected.

Found a real credential?

If exposed, revoke or rotate it with the provider. Deleting text alone does not invalidate a copied credential.
